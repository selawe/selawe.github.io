Kebijakan Privasi — Lepas Kotak (Unblock Cube)

Terakhir diperbarui: 14 November 2026

Ringkasan

Lepas Kotak adalah game puzzle yang dapat dimainkan sepenuhnya secara offline. Aplikasi tidak mengumpulkan nama, email, nomor telepon, lokasi, kontak, atau pengenal periklanan. Tidak ada iklan dan tidak ada pelacakan pihak ketiga.

Data yang disimpan di perangkat Anda

Data berikut disimpan hanya di perangkat Anda (penyimpanan lokal aplikasi) dan tidak dikirim ke mana pun kecuali Anda menggunakan fitur Peringkat:

  • Rekor skor dan bintang per level.
  • Pilihan bahasa (Indonesia/English) dan preferensi suara.
  • Pengenal instalasi acak (token) yang dibuat otomatis di perangkat.

Menghapus aplikasi akan menghapus data ini.

Data yang dikirim saat menggunakan fitur Peringkat (opsional)

Fitur Peringkat bersifat opsional. Jika dan hanya jika Anda membukanya saat online, aplikasi mengirim data berikut melalui koneksi aman (HTTPS) ke server leaderboard kami:

  • Pengenal instalasi acak (token) — bukan identitas pribadi, tidak terkait nama, email, atau akun apa pun.
  • Data permainan per level: urutan langkah, skor, dan waktu penyelesaian.

Data ini digunakan semata-mata untuk menghitung dan menampilkan papan peringkat. Server memverifikasi ulang langkah permainan untuk mencegah skor palsu. Kami tidak menjual atau membagikan data ini kepada pihak ketiga untuk tujuan periklanan.

Izin aplikasi

Aplikasi hanya meminta izin INTERNET, yang digunakan khusus untuk sinkronisasi fitur Peringkat opsional. Tidak ada izin lokasi, kamera, kontak, penyimpanan eksternal, atau mikrofon.

Anak-anak

Aplikasi tidak ditujukan untuk mengumpulkan data pribadi dari siapa pun, termasuk anak-anak. Data permainan yang dikirim tidak mengandung informasi yang dapat mengidentifikasi seseorang.

Penyimpanan dan penghapusan data peringkat

Karena identitas bersifat acak per instalasi, data peringkat tidak dapat dikaitkan dengan pribadi Anda. Untuk permintaan penghapusan data peringkat, hubungi kami di santosahw@gmail.com.
